# sims-portfolio

Прототип механики сайта-портфолио для двух людей в духе The Sims: лоу-поли комната в эстетике PS1, два персонажа, ходьба по клеткам, радиальное меню, действие с компьютером. Арт заглушечный — важно, чтобы работало и ощущалось как игра.

## Как общаться

Владелец — дизайнер без опыта разработки. Объясняй простыми словами, без жаргона. После каждого этапа сам проверяй в браузере, показывай скриншоты, делай коммит и останавливайся.

## Стек

- Vite + обычный JavaScript + Three.js. Без React и игровых движков.
- Весь контент (персонажи, мебель, действия, тексты, настройки PS1) — только в `src/data.js`. Ничего из этого не зашивать в код.
- Запуск: `npm run dev`. Для проверки в приложении — конфигурация `sims-portfolio` в `.claude/launch.json` (порт 5183).

## Договорённости о сетке

- Клетка — `[столбец, ряд]`. `[0, 0]` — дальний угол, где сходятся стены. Столбцы растут вдоль задней стены (ось X), ряды — к зрителю (ось Z). Одна клетка = 1 единица.
- Стены: `north` (вдоль ряда 0) и `west` (вдоль столбца 0). Передние срезаны.
- Направления: `north` = −Z, `south` = +Z, `west` = −X, `east` = +X.
- Стул не блокирует проход: персонаж встаёт на его клетку и садится.

## Модели персонажей

Kenney Mini Characters (CC0, kenney.nl/assets/mini-characters). Скачаны с копии на GitHub (`ivanlarios22/Zapopan`, совпадает побайтно с `Jolomolokolo/Trackenomics`). Лежат в `public/models/people/`: 12 файлов `character-{female|male}-{a…f}.glb` + общая текстура-палитра `Textures/colormap.png` (на неё ссылаются все glb). Модель выбирается полем `model` у персонажа в `data.js`, цвет `color` — только акцент интерфейса (модели не перекрашиваем).

- Скелет: `root`, `torso`, `leg-left/right`, `arm-left/right`, `head`. Модель смотрит на +Z. Рост 0.776 ед. модели, масштаб `SCALE` = 1.5 / 0.776.
- Анимации (32): static, idle, walk, sprint, jump, fall, crouch, sit, drive, die, pick-up, emote-yes, emote-no, holding-*, attack-*, interact-right/left, wheelchair-*.
- Нет «помахать» и «встать». Взмах — кодом (`Character.wave()`: поворот `arm-right` вокруг локальной Z поверх анимации). Вставание — crossfade sit → idle (сделать на этапе 4).
- Поза `sit`: `root` опускается на 0.15 ед. модели, таз оказывается ~0.026 ед. над точкой персонажа, ноги вперёд (~0.14). Чтобы сесть на стул с сиденьем на высоте `h`, персонажа поднимаем на `h − 0.026·SCALE` и сдвигаем назад к спинке. Сиденье стула сейчас 0.49 (верх).
- Скорость шага: `WALK_CYCLE_SPEED` = 0.915 ед. модели/с (амплитуда стопы 0.305 за полцикла 0.33 с).

## Требования

**Комната.** ~6×6 клеток, видны две дальние стены. Камера фиксированная, изометрическая, ортографическая (угол — как в `reference/02-camera-grid.webp`). Мебель из примитивов в коде: стол с компьютером и стулом, диван, книжная полка, торшер, окно, ковёр. Текстуры процедурные 32×32, фильтрация nearest.

**PS1.** Рендер ~320 px по высоте с растягиванием без сглаживания. Дрожание вершин — добавлять в стандартные материалы (через `onBeforeCompile`), не заменять их своими, иначе сломается скелетная анимация. Уменьшение палитры + дизеринг финальным проходом. Плоское освещение, лёгкий туман. Кнопка «PS1 вкл/выкл» в углу. Аффинное искажение текстур НЕ делаем (камера ортографическая — эффекта не видно). Едва заметное покачивание камеры, чтобы дрожание читалось (выключатель в `data.js`).

**Персонажи.** Два лоу-поли человека (разные модели Kenney), имена и данные из `data.js`. Переходы анимаций через crossfade.

**Ходьба.** A* по клеткам без библиотек, в обход мебели. Поворот по направлению, Walking в пути, Idle на месте. Клик по полу — идёт выбранный. Новый клик на ходу перестраивает маршрут без рывка. Клик по занятой клетке — идти к ближайшей свободной. Столкновения персонажей не учитываем.

**Отладка.** Клавиша G: сетка клеток, занятые — красным, текущий маршрут.

**Интерфейс** (HTML поверх 3D; по мотивам `reference/`, но без логотипов и фирменных элементов Симс, никакого зелёного кристалла):
- Слева колонка портретов, выбранный подсвечен (`reference/03-portraits-panel.png`). Клик по портрету или по персонажу в сцене выбирает.
- Под выбранным — светящееся кольцо.
- Наведение на интерактивный объект/персонажа — светлая обводка по силуэту (запасной вариант — подсветка яркостью).
- Радиальное меню у курсора: «таблетки» по кругу с точками-соединителями, в центре портрет выбранного (`reference/01-radial-menu.png`). Короткая анимация появления, клик мимо закрывает, у края экрана не вылезает за границы.
- Нижняя панель: портрет и имя, 3–4 черты, текущее действие с крестиком отмены, часы (реальное местное время).
- Клики по интерфейсу не проваливаются в сцену. Только десктоп с мышью.

**Взаимодействия.**
- Компьютер: «Показать работы» и «Ссылки». Персонаж идёт к стулу → поворачивается к столу → Sitting → через секунду панель с данными выбранного → закрытие → Standing → Idle.
- Действие — цепочка шагов, описанная в `data.js`. Отмена (крестик или клик по полу) работает на любом шаге, включая дорогу.
- Стул занят — пункт меню неактивен с подписью «Занято».
- Клик по персонажу: «Помахать» (машет тот, по кому кликнули) и «О себе» (его текст).
- Остальная мебель не интерактивна, но добавляется так же через `actions` в `data.js`.

## Как устроен код

- `src/main.js` — сцена, камера (вписывается в экран с отступами под интерфейс: `SCREEN_MARGINS`), свет, цикл отрисовки, кнопки. `toScreen()` переводит точку мира в CSS-пиксели с учётом PS1-растяжения; для кликов мышью нужен обратный перевод через тот же `view`.
- `src/room.js` — пол, стены, мебель по `type` из `data.js` (`builders`). У каждого предмета `userData.furnitureId` и `userData.interactive`.
- `src/ps1.js` — `applyPS1(object)` включает дрожание вершин во всех материалах объекта (вызывать и для роботов); `PS1Pass` — рендер в низком разрешении + палитра + дизеринг.
- `src/grid.js` — занятые клетки и отладочный слой (`setPath(points)` для маршрута).
- `src/textures.js` — процедурные текстуры.
- `src/characters.js` — `loadModel(name)` (с кэшем, текстура nearest) и класс `Character`: копия модели через `SkeletonUtils.clone`, материалы → Lambert с той же текстурой, `play(key)` с crossfade (`'wave'` → `wave()`), `wave()` возвращает Promise, `walkTo(c, r)`, `update(dt)`.
- `src/pathfinding.js` — A* в 8 направлениях без срезания углов, `nearestFreeCell`.
- Клики: `pick(x, y)` в `main.js` → `{ type: 'character' | 'object' | 'floor', … }` с учётом PS1-растяжения (`view`). Клик по НЕвыбранному персонажу выбирает его, по выбранному — радиальное меню `characterActions`; по интерактивному предмету — меню его `actions`; по полу — отменить задачу (персонаж встанет) и идти.
- Действия: `src/actions.js` → `performAction()` собирает цепочку шагов из полей действия в `data.js` и запускает её через `Character.runTask(activity, steps)`. Шаги ждут через `task.step(promise)` — при отмене сразу выходят с `Cancelled`; «уборка» (`task.onCleanup`) выполняется в обратном порядке: закрыть панель → встать → остановиться → освободить место. `occupancy` (Map в `main.js`): ключ `sitOn` или id предмета → персонаж; занятое место в меню — `disabled` + «Занято».
- Ожидания у персонажа: `until(pred)`, `wait(sec)`, `walkToAsync`, `faceTo(yaw)`, `tweenTo`, `sitDown(seat)` (подходит к `seat.approach`, затем опускается на сиденье), `standUp()` (обратно в `standSpot`). Точка посадки — `seatPoint(item)` в `room.js` по таблице `SEATS` (стул: подход сзади, диван: спереди). Тень и кольцо выбора держатся на полу, когда персонаж поднят.
- Меню — `src/menu.js` (`open({x, y, portrait, accent, items, onPick})`, сам не вылезает за края). Панели — `src/panels.js` (`open(kind, characterData)` → `{ closed, close }`); панель одна на экране, новая закрывает предыдущую — и завершает действие того, кто её открыл. Панель стоит слева у портретов, чтобы компьютер был виден.
- Ковёр пропадал из-за дрожания вершин, а не точности глубины (буфер 24-битный): пол — два огромных треугольника, при прыжке углов по сетке его плоскость «наклоняется» и перекрывает ковёр. Поэтому у пола и ковра `userData.noSnap = true` (их пропускает `applyPS1`). Проверка: рендер при 300 положениях камеры и чтение пикселей ковра — 0 промахов. Слои: ковёр 0.02, тень 0.035, кольцо 0.05; камера near/far = 4/40.
- Дрожание у персонажей отдельной силой: `ps1.characterSnap` в `data.js` (0 — выкл, по умолчанию; 2 — вдвое слабее; 1 — как у комнаты). При 1 мелкие детали лица (глаза, очки) прыгают сквозь лицо и выглядят рваными. Сила — uniform `uSnapScale` на материал (`material.userData.snapScale`); силуэт обводки берёт силу обводимого объекта (`pass.render(..., outlineSnap)`).
- Проверено на этапе 4: полное действие, «Ссылки», отмена по дороге (клик по полу), отмена сидя (крестик), смена персонажа, пока первый сидит, «Занято» у второго, взмах, «О себе», меню у краёв экрана, раскомментированный пример с диваном.
- Кадр всегда идёт через `PS1Pass` (`ps1.js`), в том числе без PS1 (тогда масштаб 1, без палитры, MSAA 4). Обводка: наведённый объект переносится в слой `OUTLINE_LAYER` (`setOutlined`), рисуется белым силуэтом в `pass.mask`, финальный шейдер рисует светлый контур по краю силуэта. Мешам, которые не нужно обводить и ловить кликом (тень, кольцо), ставим `userData.noOutline` и пустой `raycast`.
- `src/ui.js` — колонка портретов и нижняя панель (`createUI` → `setPortrait`, `setSelected`, `setActivity({icon,label}|null)`). Слой `#ui` с `pointer-events: none`, панели внутри — `auto`, поэтому клики по интерфейсу не попадают в сцену.
- `src/portraits.js` — `renderPortrait(renderer, gltf)` снимает голову модели в 96×96 (dataURL), в интерфейсе показывается с `image-rendering: pixelated`.
- Кольцо выбора — `createSelectionRing()` в `characters.js`, переносится в `root` выбранного персонажа. У ковра нельзя ставить `polygonOffset` — он перекрывает кольцо и тень.
- Проверка в скрытой панели браузера: она рисует ~5 кадров/с, поэтому ходьба там медленнее (dt ограничен 0.1 с). Это не баг.
- В консоли браузера доступен `window.__app` для проверок.

## Проверка

- `window.__app` есть только в `npm run dev` (`import.meta.env.DEV`); в сборке его нет. `vite.config.js`: `base: './'`, модели грузятся от `import.meta.env.BASE_URL` — сайт работает из подпапки.
- Встроенная панель браузера Claude, когда скрыта, рисует 0–5 кадров/с, и игра там «стоит». Для проверок логики гонять время вручную: вызывать `ch.update(1/30)` для всех `__app.characters` в цикле с `await Promise.resolve()`, пока не выполнится условие. Пиксели проверять через `__app.pass.render(...)` + `gl.readPixels` в той же задаче.
