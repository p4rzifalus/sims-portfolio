# sims-portfolio

Прототип сайта-портфолио для двух людей в духе The Sims. Маленькая комната в эстетике первой PlayStation и два человечка. Их можно выбирать, водить по комнате и сажать за компьютер, где открываются работы и ссылки.

Это прототип механики: мебель собрана из кубиков, персонажи — готовые бесплатные модели, тексты — заглушки. Зато всё работает и ощущается как игра.

## Как запустить

Нужен установленный [Node.js](https://nodejs.org), свежая версия (22 или новее). Откройте Терминал в папке проекта и выполните — только в первый раз:

```bash
npm install
```

Потом каждый раз, когда хотите посмотреть сайт:

```bash
npm run dev
```

Терминал напечатает адрес вида `http://localhost:5173` — откройте его в браузере. Пока терминал открыт, сайт работает и сам обновляется, когда вы сохраняете файлы. Остановить — `Ctrl+C` в терминале.

Чтобы получить готовый сайт для публикации, выполните `npm run build`. Появится папка `dist` — её содержимое можно выложить на любой хостинг, например GitHub Pages.

## Как играть

- **Выбрать персонажа** — клик по портрету слева или по человечку в комнате. Под выбранным светится кольцо.
- **Пойти** — клик по полу. Персонаж обойдёт мебель.
- **Компьютер** — клик по нему → «Показать работы» или «Ссылки». Персонаж подойдёт, сядет, через секунду откроется панель. Закрыли панель — он встал.
- **Помахать, рассказать о себе** — клик по уже выбранному персонажу.
- **Отменить** — красный крестик в нижней панели, клик по полу или `Esc`.
- **PS1 вкл/выкл** — кнопка справа вверху: сравнить «как на приставке» и обычную картинку.
- **Сетка** — клавиша `G`: клетки пола с номерами, занятые мебелью — красные, путь персонажа — зелёный. Удобно, чтобы расставлять мебель.

## Как это устроено

Сайт — одна страница. На ней 3D-сцена, нарисованная библиотекой Three.js, а поверх неё обычный HTML-интерфейс: портреты, панели, меню. Код разбит на файлы по смыслу, все они лежат в папке `src`.

**`data.js` — весь контент.** Имена, тексты, работы, ссылки, черты, цвета, расстановка мебели, что можно делать с предметами, настройки эффекта PS1. Это единственный файл, который нужно трогать, чтобы менять наполнение. Подсказки написаны прямо в нём.

**`main.js` — дирижёр.** Создаёт сцену и камеру, загружает персонажей, слушает мышь. Решает, что значит клик: выбрать человечка, открыть меню или пойти. 60 раз в секунду он двигает персонажей и перерисовывает кадр.

**`room.js` — комната и мебель.** Собирает пол, две стены и каждый предмет из `data.js` из простых коробок и цилиндров. Здесь же записано, где у стула и дивана сиденье и с какой стороны к ним подходить.

**`textures.js` — текстуры.** Доски пола, обои, дерево, ткань, ковёр, небо в окне и экран компьютера. Это крошечные картинки 32×32 пикселя, нарисованные кодом попиксельно.

**`ps1.js` — эффект первой PlayStation.** Он состоит из трёх частей:
- **дрожание вершин** — углы предметов «прыгают» по грубой сетке;
- **низкое разрешение** — картинка рисуется в маленьком размере и растягивается крупными пикселями;
- **урезанная палитра** — меньше оттенков, а на переходах цвета появляется «зерно» (дизеринг).

Здесь же рисуется светлая обводка вокруг того, на что наведена мышь.

**`grid.js` и `pathfinding.js` — клетки и маршруты.** Первый знает, какие клетки заняты мебелью, и рисует отладочную сетку. Второй ищет кратчайший путь по свободным клеткам в обход мебели, тем же способом, что и в настоящих играх.

**`characters.js` — персонажи.** Загружает модель, включает анимации (стоять, идти, сидеть) с плавными переходами. Ведёт человечка по маршруту и поворачивает его по ходу движения. Ещё здесь сделаны взмах рукой, посадка и вставание, а также светящееся кольцо под выбранным.

**`actions.js` — действия.** Превращает описание действия из `data.js` в цепочку шагов:

> дойти → повернуться → сесть или помахать → открыть панель → дождаться, пока её закроют

Действие можно прервать на любом шаге. Тогда персонаж «прибирается» за собой: закрывает панель, встаёт и освобождает место.

**`menu.js` — радиальное меню.** Кнопки-«таблетки» по кругу вокруг курсора, в центре портрет. Меню само следит, чтобы не вылезти за край экрана.

**`panels.js` — панели.** Работы (сетка карточек), ссылки (список) и «о себе» (портрет и текст).

**`ui.js` и `portraits.js` — интерфейс.** Портреты слева и нижняя панель: имя, черты, текущее действие с крестиком, часы. Портреты — это снимки голов самих 3D-моделей, сделанные при загрузке.

**`style.css` — оформление интерфейса**: цвета, скругления, анимации появления.

**`public/models/people/` — модели людей.** Это 12 персонажей из набора [Kenney Mini Characters](https://kenney.nl/assets/mini-characters) с лицензией CC0: можно использовать где угодно, указывать автора не обязательно. Все модели используют одну общую текстуру-палитру из `Textures/colormap.png`.

## Как поменять контент

Всё ниже — правки в файле `src/data.js`. Сохранили файл — страница обновилась сама.

Общие правила, чтобы ничего не сломать:
- **текст** всегда в кавычках: `'Вот так'`;
- **запятые:** после каждой строки с параметром стоит запятая;
- **цвета** пишутся как в Figma: `'#e8833a'`.

### Имя, текст «о себе», черты

Найдите блок персонажа (`id: 'p1'` или `id: 'p2'`) и поменяйте `name`, `about`, `traits`. Черт может быть сколько угодно, но в панель красиво помещается 3–4. У каждой черты есть значок (любой эмодзи) и подпись:

```js
traits: [
  { icon: '🎨', label: 'Дизайнер' },
  { icon: '☕', label: 'Кофеман' },
],
```

### Добавить работу

1. Положите картинку в папку `public/works/` (создайте её, если её нет), например `public/works/poster.jpg`.
2. В блоке персонажа в списке `works` добавьте строку:

```js
{ title: 'Афиша фестиваля', description: '2025, айдентика', image: 'works/poster.jpg', url: 'https://behance.net/...' },
```

`image` и `url` можно оставить пустыми (`''`). Без картинки будет цветная заглушка с номером, без ссылки карточка просто не кликается.

### Добавить ссылку

В списке `links` персонажа:

```js
{ label: 'Dribbble', url: 'https://dribbble.com/...' },
```

### Поменять внешность

Поле `model` у персонажа. Варианты: от `character-female-a` до `character-female-f` и от `character-male-a` до `character-male-f`. Поле `color` — фирменный цвет персонажа: им окрашены кольцо под ногами и рамка портрета.

### Передвинуть мебель

У каждого предмета есть `cells` — клетки, которые он занимает, и `facing` — куда он смотрит. Номера клеток видны по клавише `G`: первая цифра — столбец, вторая — ряд.

Если переносите стол со стулом, поменяйте у действий компьютера `goTo` — клетку, куда подходит персонаж. Она должна быть свободной.

### Сделать предмет интерактивным

Добавьте предмету список `actions`. Готовый пример — у дивана: уберите `//` в начале строк от `actions: [` до `],` — и диван станет кликабельным. На нём можно будет «Отдохнуть», а потом откроется панель «О себе». Все поля действия описаны в комментарии над списком мебели:
- куда подойти;
- куда повернуться;
- что сделать: сесть или помахать;
- на что сесть;
- какую панель открыть;
- занимает ли действие место.

Новый **вид** мебели (например, кровать или холодильник) уже требует кода в `room.js`: там описано, из каких коробок он собран.

### Подкрутить «приставочность»

Блок `ps1` в начале `data.js`:
- `renderHeight` — сколько пикселей по высоте (меньше — крупнее пиксели);
- `vertexSnap` — дрожание мебели (меньше — сильнее);
- `characterSnap` — дрожание персонажей (по умолчанию выключено: у маленьких лиц от него «рвутся» глаза);
- `colorLevels` и `dither` — грубость палитры и «зерно»;
- `fogStrength` — туман;
- `cameraSway` — лёгкое покачивание камеры.

## Если что-то сломалось

Чаще всего это пропущенная запятая или кавычка в `data.js`: тогда страница станет пустой. Откройте консоль браузера — в Chrome это `Cmd+Option+J`. Там будет красная строка с названием файла и номером строки, где ошибка. Если не понятно, откатите файл к прошлой версии через git или пришлите текст ошибки Claude.

## Известные ограничения

- **Панель на экране одна.** Если, пока первый сидит за компьютером, открыть «О себе» второго, первый закроет работы и встанет.
- **Персонажи проходят сквозь друг друга** — так задумано в ТЗ.
- **Только компьютер с мышью**: на телефоне интерфейс не адаптирован.
- **Анимации «встать» в наборе моделей нет**, это плавный переход из позы сидя в стойку.
