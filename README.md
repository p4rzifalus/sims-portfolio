# sims-portfolio

Прототип сайта-портфолио для двух людей в духе The Sims: комната в эстетике PS1, два персонажа, ходьба по клеткам, меню действий.

**Состояние:** готов этап 4 из 5 — вся механика работает. Осталась полировка и подробный README «как это устроено».

Как играть:
- **Выбрать персонажа** — клик по портрету слева или по человеку в комнате.
- **Пойти** — клик по полу.
- **Компьютер** — клик по нему, в меню «Показать работы» или «Ссылки». Персонаж подойдёт, сядет, через секунду откроется панель. Закрыли панель — встал.
- **Персонаж** — клик по уже выбранному: «Помахать» или «О себе».
- **Отменить** — красный крестик в нижней панели или клик по полу.

Чтобы сменить внешность персонажа, поменяйте поле `model` в `src/data.js`: есть 12 вариантов, от `character-female-a` до `character-male-f`.

Кнопка «PS1» в правом верхнем углу включает и выключает эффект. Клавиша G (или кнопка «G — сетка») показывает клетки пола с номерами — по ним удобно расставлять мебель в `src/data.js`.

## Как запустить

Нужен установленный Node.js. В терминале, находясь в папке проекта:

```bash
npm install
```

```bash
npm run dev
```

Вторая команда напечатает адрес вида `http://localhost:5173` — откройте его в браузере. Чтобы остановить, нажмите Ctrl+C в терминале. `npm install` нужен только один раз.

## Что где лежит

- `src/data.js` — весь контент: имена, цвета, тексты, работы, ссылки, расстановка мебели, настройки эффекта PS1. Его можно править без знания кода, подсказки — в самом файле.
- `src/main.js` — код, который всё собирает и показывает.
- `public/models/people/` — 12 моделей людей [Kenney Mini Characters](https://kenney.nl/assets/mini-characters) (лицензия CC0: можно использовать где угодно, указывать автора не обязательно, но приятно — Kenney).
- `reference/` — скриншоты, по мотивам которых делается интерфейс.
- `CLAUDE.md` — техзадание и договорённости для Claude.
