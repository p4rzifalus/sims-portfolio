# sims-portfolio

Прототип сайта-портфолио для двух людей в духе The Sims. Маленькая комната в эстетике первой PlayStation и два человечка. Их можно выбирать, водить по комнате и сажать за макбуки, где открываются работы и ссылки.

Это прототип механики: мебель собрана из кубиков, персонажи — готовые бесплатные модели, тексты — заглушки. Зато всё работает и ощущается как игра.

**Сайт:** https://p4rzifalus.github.io/sims-portfolio/

## Как обновить сайт

Сайт пересобирается и публикуется сам при каждой отправке изменений на GitHub (в ветку `main`). Поправили, например, `data.js` — сохраните изменения в git и отправьте:

```bash
git add -A && git commit -m "Обновил тексты" && git push
```

Через 1–2 минуты новая версия появится по адресу выше. Ход сборки виден на GitHub во вкладке **Actions** репозитория.

## Как запустить

Нужен установленный [Node.js](https://nodejs.org), свежая версия (22 или новее). Откройте Терминал в папке проекта и выполните — только в первый раз:

```bash
npm install
```

Потом каждый раз, когда хотите посмотреть сайт:

```bash
npm run dev
```

Терминал напечатает адрес вида `http://localhost:5173` — откройте его в браузере. Пока терминал открыт, сайт работает и сам обновляется, когда вы сохраняете файлы. Остановить — `Ctrl+C` в терминале.

Чтобы собрать сайт вручную, выполните `npm run build` — появится папка `dist`, её содержимое можно выложить на любой хостинг. Для GitHub Pages это делать не нужно: там сборка автоматическая (см. ниже).

## Как играть

- **Выбрать персонажа** — клик по портрету слева или по человечку в комнате. Под выбранным светится кольцо.
- **Пойти** — клик по полу. Персонаж обойдёт мебель.
- **Компьютер** — клик по нему → «показать работы» или «ссылки». Персонаж подойдёт, сядет, через секунду откроется панель. Закрыли панель — он встал.
- **Помахать, рассказать о себе** — клик по уже выбранному персонажу.
- **Отменить** — красный крестик в нижней панели, клик по полу или `Esc`.
- **PS1 вкл/выкл** — кнопка справа вверху: сравнить «как на приставке» и обычную картинку.
- **Сетка** — клавиша `G`: клетки пола с номерами, занятые мебелью — красные, путь персонажа — зелёный. Удобно, чтобы расставлять мебель.

## Как это устроено

Сайт — одна страница. На ней 3D-сцена, нарисованная библиотекой Three.js, а поверх неё обычный HTML-интерфейс: портреты, панели, меню. Код разбит на файлы по смыслу, все они лежат в папке `src`.

**`data.js` — весь контент.** Имена, тексты, работы, ссылки, досье (потребности, интересы, работа, отношения), цвета, расстановка мебели, что можно делать с предметами, настройки эффекта PS1. Это единственный файл, который нужно трогать, чтобы менять наполнение. Подсказки написаны прямо в нём.

**`main.js` — дирижёр.** Создаёт сцену и камеру, загружает персонажей, слушает мышь. Решает, что значит клик: выбрать человечка, открыть меню или пойти. Здесь же камера плавно подъезжает к плакату и обратно. 60 раз в секунду он двигает персонажей и перерисовывает кадр.

**`room.js` — комната и мебель.** Собирает пол, две стены и каждый предмет из `data.js` из простых коробок и цилиндров. Здесь же записано, где у стула и дивана сиденье и с какой стороны к ним подходить.

**`textures.js` — текстуры.** Доски пола, обои, дерево, ткань, ковёр, экраны ноутбуков. Это крошечные картинки 32×32 пикселя, нарисованные кодом попиксельно. Крупнее только вид из окна (петербург белой ночью: шпиль, купол, разведённый мост, нева, набережная — 32 пикселя на клетку окна) и плакат: картинка из `public/images/` уменьшается до 240×300 пикселей (или, если картинки нет, текст из `data.js` огрубляется до чётких пикселей).

**`ps1.js` — эффект первой PlayStation.** Он состоит из трёх частей:
- **дрожание вершин** — углы предметов «прыгают» по грубой сетке;
- **низкое разрешение** — картинка рисуется в маленьком размере и растягивается крупными пикселями;
- **урезанная палитра** — меньше оттенков, а на переходах цвета появляется «зерно» (дизеринг).

Здесь же рисуется светлая обводка вокруг того, на что наведена мышь.

**`grid.js` и `pathfinding.js` — клетки и маршруты.** Первый знает, какие клетки заняты мебелью, и рисует отладочную сетку. Второй ищет кратчайший путь по свободным клеткам в обход мебели, тем же способом, что и в настоящих играх.

**`characters.js` — персонажи.** Загружает модель, включает анимации (стоять, идти, сидеть) с плавными переходами. Ведёт человечка по маршруту и поворачивает его по ходу движения. Ещё здесь сделаны взмах рукой, посадка и вставание, книга и ноутбук в руках (руки поворачиваются кодом поверх анимации), а также светящееся кольцо под выбранным.

**`props.js` — предметы в руках.** Книга и ноутбук из коробок, как мебель.

**`actions.js` — действия.** Превращает описание действия из `data.js` в цепочку шагов:

> дойти → повернуться → сесть или помахать → достать предмет → открыть панель → дождаться, пока её закроют

Действие можно прервать на любом шаге. Тогда персонаж «прибирается» за собой: закрывает панель, убирает книгу или ноутбук, встаёт и освобождает место.

**`menu.js` — радиальное меню.** Кнопки-«таблетки» по кругу вокруг курсора, в центре портрет. Меню само следит, чтобы не вылезти за край экрана.

**`panels.js` — панели.** Работы (сетка карточек), ссылки (список), «о себе» (портрет и текст) и общая панель книжного шкафа (каналы и курс).

**`ui.js` и `portraits.js` — интерфейс.** Портреты слева и нижняя панель из трёх блоков: портрет с именем, действием, интересами и часами; работа; потребности и отношения. Портреты — это снимки голов самих 3D-моделей, сделанные при загрузке.

**`style.css` — оформление интерфейса**: цвета, скругления, анимации появления.

**`public/models/people/` — модели людей.** Это 12 персонажей из набора [Kenney Mini Characters](https://kenney.nl/assets/mini-characters) с лицензией CC0: можно использовать где угодно, указывать автора не обязательно. Все модели используют одну общую текстуру-палитру из `Textures/colormap.png`. У `character-female-a` из рук убраны костыли — это сделал скрипт `tools/remove-hand-props.mjs`.

## Как поменять контент

Всё ниже — правки в файле `src/data.js`. Сохранили файл — страница обновилась сама.

Общие правила, чтобы ничего не сломать:
- **текст** всегда в кавычках: `'вот так'`;
- **с маленькой буквы:** все тексты на сайте пишутся с маленькой буквы, аббревиатуры — большими (PS1, ПИН, ИИ);
- **висячие предлоги** сайт убирает сам: короткие слова («в», «на», «и»…) переносятся на новую строку вместе со следующим словом;
- **запятые:** после каждой строки с параметром стоит запятая;
- **цвета** пишутся как в Figma: `'#e8833a'`.

### Имя, текст «о себе», досье

Найдите блок персонажа (`id: 'p1'` или `id: 'p2'`) и поменяйте `name` и `about`. Там же — данные для нижней панели:

```js
// потребности: насколько заполнена каждая шкала, от 0 до 10
needs: { hunger: 6, comfort: 8, energy: 4, fun: 9, social: 8, environment: 10 },
// интересы: значки под портретом, подпись видна при наведении (на телефоне — по нажатию)
interests: [
  { icon: '🖌️', label: 'рисование' },
  { icon: '📚', label: 'книжный дизайн', description: 'можно добавить пояснение' },
],
// работа: место и роль
jobs: [
  { place: 'щелочь', role: 'препод курса ПИН' },
],
// отношения: id другого персонажа и цифра дружбы от −100 до 100
relationships: [{ who: 'p2', friendship: 100 }],
```

Названия потребностей, вкладок правого блока и заголовок «работа» — в блоке `dossier` (под персонажами). Шкала зелёная, когда заполнена больше чем на 60%, жёлтая — от 30%, красная — меньше. Столбик рядом с потребностями — настроение, среднее всех шкал. Клик по портрету во вкладке «отношения» выбирает этого персонажа.

### Письмо-приветствие

Блок `welcome` в конце файла: `text` — текст письма, `title` — заголовок, `icon` — значок, `delay` — через сколько секунд после открытия сайта оно появится. `show: false` — письмо не показывается.

### Добавить работу

1. Положите картинку в папку `public/works/` (создайте её, если её нет), например `public/works/poster.jpg`.
2. В блоке персонажа в списке `works` добавьте строку:

```js
{ title: 'Афиша фестиваля', description: '2025, айдентика', image: 'works/poster.jpg', url: 'https://behance.net/...' },
```

`image` и `url` можно оставить пустыми (`''`). Без картинки будет цветная заглушка с номером, без ссылки карточка просто не кликается.

### Добавить ссылку

В списке `links` персонажа:

```js
{ label: 'Dribbble', url: 'https://dribbble.com/...' },
```

### Поменять внешность

Поле `model` у персонажа. Варианты: от `character-female-a` до `character-female-f` и от `character-male-a` до `character-male-f`. Поле `color` — фирменный цвет персонажа: им окрашены кольцо под ногами и рамка портрета.

### Передвинуть мебель

У каждого предмета есть `cells` — клетки, которые он занимает, и `facing` — куда он смотрит. Номера клеток видны по клавише `G`: первая цифра — столбец, вторая — ряд.

Если переносите стол со стульями, поменяйте у действий макбуков `goTo` — клетку, куда подходит персонаж (за стулом). Она должна быть свободной. У макбука `cells` — та клетка стола, на которой он стоит, `sitOn` в его действиях — id его стула.

Предметы на стене (окно, плакат) вместо `facing` описываются полем `wall`: `'north'` — задняя стена, `'west'` — левая; `cells` — над какими клетками висят. Окно растягивается на все свои клетки.

### Поменять плакат

1. Положите картинку с пропорциями 4:5 в `public/images/`.
2. У предмета `poster` поменяйте `image` — путь к ней, например `'images/pin-poster.jpg'`.

По клику камера подъезжает к плакату. Надпись и адрес кнопки внизу — в `closeUp`: `button` и `url`. `height` — на какой высоте висит плакат.

### Каналы в книжном шкафу

Блок `panels` → `shelf` → `links`. У каждой строки `label` — надпись, `note` — серая подпись справа (например, `@ник`), `url` — ссылка.

### Сделать предмет интерактивным

Добавьте предмету список `actions`. Готовые примеры — у макбуков (сесть и открыть панель), книжного шкафа (достать книгу) и дивана (сесть вдвоём и работать на ноутбуке). Все поля действия описаны в комментарии над списком мебели:
- куда подойти (`goTo`, или `spots` — несколько мест на выбор);
- куда повернуться;
- что сделать: сесть или помахать;
- на что сесть;
- что достать: книгу или ноутбук;
- какую панель открыть;
- занимает ли действие место.

Предмет на стене вместо меню может приближать камеру — поле `closeUp`, как у плаката.

Новый **вид** мебели (например, кровать или холодильник) уже требует кода в `room.js`: там описано, из каких коробок он собран.

### Подкрутить «приставочность»

Блок `ps1` в начале `data.js`:
- `renderHeight` — сколько пикселей по высоте (меньше — крупнее пиксели);
- `vertexSnap` — дрожание мебели (меньше — сильнее);
- `characterSnap` — дрожание персонажей (по умолчанию выключено: у маленьких лиц от него «рвутся» глаза);
- `colorLevels` и `dither` — грубость палитры и «зерно»;
- `fogStrength` — туман;
- `cameraSway` — лёгкое покачивание камеры.

## Если что-то сломалось

Чаще всего это пропущенная запятая или кавычка в `data.js`: тогда страница станет пустой. Откройте консоль браузера — в Chrome это `Cmd+Option+J`. Там будет красная строка с названием файла и номером строки, где ошибка. Если не понятно, откатите файл к прошлой версии через git или пришлите текст ошибки Claude.

## Известные ограничения

- **Панель на экране одна.** За макбуки можно сесть вдвоём, но если, пока первый смотрит работы, открыть панель второго, панель первого закроется. Сам он продолжит сидеть за макбуком, пока его не отменят.
- **Персонажи проходят сквозь друг друга** — так задумано в ТЗ.
- **Только компьютер с мышью**: на телефоне интерфейс не адаптирован.
- **Анимации «встать» в наборе моделей нет**, это плавный переход из позы сидя в стойку.
